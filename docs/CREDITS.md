# Asset provenance

- **Prism Isles key art / Pip:** original AI-generated illustration created for this project. Source asset: `assets/art/prism_isles.png`. Generated October 9, 2026, with OpenAI's image generation tool. The illustration was copied into the project without postprocessing.
- **Gems, icons, and scenery accents:** original SVG artwork and Godot vector drawing authored for this project. SVGs remain editable text/vector assets; no emoji artwork or third-party game assets are used.
- **Music and sounds:** original synthesized PCM waveforms authored for this project: a 25.6-second looping arpeggio, UI chime, match chime, success phrase, and invalid-swap tone. No external samples.
- **Fredoka:** typeface by the Fredoka Project Authors, sourced from the Google Fonts repository. Licensed under the SIL Open Font License 1.1; the complete license is included at `assets/fonts/OFL.txt`. Font axes are configured in the Godot Theme; the font binary is unmodified.

The project uses its own title, character, illustrations, layouts, and assets. It is not affiliated with Candy Crush or King.
